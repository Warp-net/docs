# Начало работы {#getting-started}

Эта страница проведет вас от загрузки до первого поста: установка десктопного приложения, выбор сети, создание аккаунта, подключение мобильного приложения и место хранения данных. Если вы держите постоянно работающий сервер, переходите к странице [Запуск узла](running-a-node.md).

У Warpnet нет центральных серверов и нет компании, которая хранит аккаунты. Приложение, которое вы устанавливаете, *и есть* ваш узел: оно хранит ваш профиль, посты, подписки и чаты на вашем компьютере и напрямую общается с другими узлами. Нигде ничего не регистрируется.

## Установка {#install}

### Компьютер {#desktop}

Скачайте приложение на странице **[warpnet.site/download](https://warpnet.site/download)**. Кнопки там загружают файлы [последнего релиза на GitHub](https://github.com/Warp-net/warpnet/releases/latest).

| Система | Файл | Что запускать |
|---|---|---|
| Windows x64 | `warpnet_windows_amd64.zip` | `warpnet.exe` |
| Linux x86-64 | `warpnet_linux_amd64.tar.gz` | `warpnet` |
| Linux ARM64 | `warpnet_linux_arm64.tar.gz` | `warpnet` |
| macOS (Intel и Apple silicon) | `warpnet_darwin.tar.gz` | `warpnet.app` |
| Linux (Snap) | `sudo snap install warpnet --beta` | `warpnet` |

Распакуйте архив и запустите файл из него. Для архива под Linux нужны установленные GTK 3 и WebKitGTK 4.1 (в Debian и Ubuntu пакет называется `libwebkit2gtk-4.1-0`).

> **Внимание:** Сборка для macOS не подписана, поэтому macOS блокирует первый запуск. Попробуйте один раз открыть `warpnet.app`, затем откройте **System Settings → Privacy & Security** («Системные настройки → Конфиденциальность и безопасность»), прокрутите вниз, нажмите **Open Anyway** и подтвердите.
{: .warning }

### Обновления {#updates}

| Откуда установлено | Как обновляется |
|---|---|
| Архив для Windows или Linux | Через минуту после запуска, а затем каждый час приложение проверяет последний релиз на GitHub. Когда выходит новая версия, оно спрашивает вас: **Update now** заменяет приложение и перезапускает его, поэтому нужно войти снова; **Later** пропускает эту версию до перезапуска приложения. Если приложение не может заменить собственный файл (он лежит в папке, куда может писать только система), оно лишь сообщает о новой версии и предлагает **Download**. |
| Snap | Приложение обновляет Snap; встроенное обновление отключено. |
| macOS | Встроенного обновления нет. Скачивайте каждую новую версию с [warpnet.site/download](https://warpnet.site/download). |

Чтобы отключить проверку, запускайте приложение с `--node.self-update=false`.

### Проверка загрузки {#verify-the-download}

У каждого архива на [странице релиза на GitHub](https://github.com/Warp-net/warpnet/releases/latest) есть файл `<name>_checksums.txt` с его хешем SHA-256 и файл `<name>_checksums.txt.sig` с подписью Ed25519 для этого файла. Проверка хеша:

```bash
sha256sum -c warpnet_linux_amd64_checksums.txt        # Linux
shasum -a 256 -c warpnet_darwin_checksums.txt          # macOS
```

В Windows выполните в PowerShell `Get-FileHash warpnet_windows_amd64.zip` и сравните хеш с указанным в `warpnet_windows_amd64_checksums.txt`.

Для проверки подписи нужен OpenSSL 3 или новее. Сохраните ключ релизов проекта в файл `release.pub`:

```text
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEA+PJtnzN+C//o1UVdUWlQkhMPrT0QTZfB+s87rLQgvUk=
-----END PUBLIC KEY-----
```

```bash
base64 -d warpnet_linux_amd64_checksums.txt.sig > listing.sig
openssl pkeyutl -verify -pubin -inkey release.pub -rawin \
  -in warpnet_linux_amd64_checksums.txt -sigfile listing.sig
```

Встроенный механизм обновления проверяет каждый релиз этим же ключом перед установкой ([`core/selfupdate/selfupdate.go`](https://github.com/Warp-net/warpnet/blob/main/core/selfupdate/selfupdate.go)).

### Телефон {#phone}

У мобильных приложений нет собственных аккаунтов: они подключаются к запущенному десктопному приложению или [удаленному узлу](running-a-node.md#remote-node).

| Платформа | Где взять |
|---|---|
| Android 7.0 или новее (64-битный ARM) | [F-Droid](https://f-droid.org/packages/site.warpnet.warpdroid/) или **Android (apk)** на [warpnet.site/download](https://warpnet.site/download) |
| iOS 17 или новее | [App Store](https://apps.apple.com/app/warpnet/id6835178022) |

Приложение можно установить уже сейчас, но подключайте его после того, как создадите аккаунт: см. [Подключение телефона](#connect-your-phone).

## Выбор сети {#choose-a-network}

У Warpnet две сети, которые никогда не пересекаются:

| Сеть | Имя | Для чего |
|---|---|---|
| Основная | `warpnet` (псевдоним `mainnet`) | Рабочая сеть. Используется по умолчанию. |
| Тестовая | `testnet` | Для экспериментов. |

Пока в выбранной сети на этом компьютере нет аккаунта, на приветственном экране под кнопкой **Sign up** есть переключатель **Network** (**Warpnet (main)** или **Testnet**). Если выбрать сеть, приложение перезапустится в ней. Из командной строки:

```bash
warpnet --node.network testnet   # тестовая сеть
warpnet --node.network mainnet   # основная сеть
```

Что нужно знать:

- У каждой сети своя папка с данными и свой аккаунт. Те же логин и пароль в другой сети дают другую идентичность.
- Узлы общаются только с узлами, у которых то же имя сети и та же мажорная версия.
- Приложение запускается в основной сети, если не указано иное. Чтобы открыть существующий аккаунт в testnet, запустите приложение с `--node.network testnet` (или с переменной окружения `NODE_NETWORK=testnet`) либо снова выберите **Testnet** на приветственном экране.
- Кошелек показывается только в testnet.

## Регистрация {#sign-up}

Нажмите **Sign up** на приветственном экране. Мастер регистрации состоит из четырех шагов и показывает индикатор прогресса.

**Шаг 1 из 4: Login.** Введите логин, с которым будете входить. Он используется ровно так, как введен (регистр букв и пробелы имеют значение), второго поля для подтверждения нет, и изменить его потом нельзя. Логин — это не ваше имя: он никогда не публикуется, а другие видят ваш профиль как `Anonymous`, пока вы не укажете имя в **Edit profile → Name**.

**Шаг 2 из 4: Important information.** Чтобы продолжить, отметьте все четыре утверждения:

| Утверждение | Кратко |
|---|---|
| User Responsibility | Вы отвечаете за то, что загружаете. Оскорбительный контент и агрессивные пользователи недопустимы: на них можно пожаловаться, их можно скрыть и заблокировать. |
| Content Distribution | Все, что вы публикуете, распространяется на другие узлы, которые хранят и показывают это. Сообщения доставляются на узлы получателей. Копии, которые другие узлы уже получили, могут остаться после удаления оригинала. |
| Local Storage Disclaimer | Ваши данные хранятся только на вашем устройстве. Потеряете доступ к устройству — потеряете аккаунт. |
| Future Advertising | В Warpnet может появиться спонсорский контент или реклама. |

**Шаг 3 из 4: Password.** Введите пароль дважды. Пункты контрольного списка становятся зелеными по мере выполнения правил, а кнопка **Next** остается неактивной, пока не выполнены все правила и оба поля не совпадают. Пароль должен содержать:

- от 8 до 32 символов
- хотя бы одну заглавную букву (A–Z)
- хотя бы одну строчную букву (a–z)
- хотя бы одну цифру (0–9)
- хотя бы один специальный символ: любой, кроме A–Z, a–z и 0–9 (`_` тоже подходит)

Пробелы в начале и в конце пароля удаляются перед использованием. Узел считает длину в байтах, поэтому буквы не из латинского алфавита (в том числе кириллица) считаются за два символа и больше.

**Шаг 4 из 4.** В окне есть ссылка на условия использования и политику конфиденциальности (они есть и в этой документации: [Условия использования](../legal/T&C.md), [Политика конфиденциальности](../legal/PRIVACY-POLICY.md)). Нажмите **Sign up**. Узел создаст зашифрованную базу данных, запустится и подключится к сети.

Затем короткий тур покажет основные части приложения. Повторить его можно пунктом **Take the tour** в меню аккаунта.

## Вход {#sign-in}

При следующих запусках на приветственном экране показывается форма **Login** и **Password**. Введите оба значения ровно так, как при регистрации, и нажмите **Log in**. Если одно из них неверно, база данных не откроется и приложение покажет ошибку.

**Sign out** в меню аккаунта останавливает ваш узел. Чтобы скрыть окно, но оставить узел работать, задайте PIN-код в **Settings → Screen lock** и используйте **Lock screen** в меню аккаунта.

## Логин и пароль — это ваша личность {#your-login-and-password-are-your-identity}

Логин и пароль вместе — это секрет, на котором держится ваш аккаунт. Из них выводятся два ключа:

| Из чего выводится | Ключ | Для чего нужен |
|---|---|---|
| логин + пароль | ключ базы данных | Шифрует локальную базу данных: профиль, посты, подписки, чаты, настройки. |
| логин + пароль + сеть | ключ идентичности | Ваш ID узла и подпись под всем, что отправляет ваш узел. |

Ни один из ключей не хранится на диске: они существуют, только пока вы в системе. Отсюда следует:

- **Сброса нет.** Ни у кого нет копии вашего логина, пароля или ключей.
- **Ни логин, ни пароль сменить нельзя.** Из другого логина или пароля получаются другой ключ базы данных и другая идентичность, поэтому они не откроют ваши существующие данные.
- **Те же логин и пароль на другом компьютере дают тот же ID узла, но не ваш аккаунт.** Ваш ID пользователя, профиль, посты, подписки и чаты хранятся в базе данных. Без копии папки с данными вы начнете с пустого профиля. См. [Резервное копирование и восстановление](backup-and-restore.md).
- **Ваше публичное имя — отдельная вещь.** Другие видят имя профиля и ID пользователя, но никогда не видят ваш логин.

## Подключение телефона {#connect-your-phone}

Приложения для Android и iOS работают через ваш узел, поэтому аккаунт, ключи и данные остаются на компьютере.

1. На компьютере войдите в Warpnet, откройте меню аккаунта и выберите **Sign in by QR-code** (вход по QR-коду). Появится QR-код.
2. Откройте приложение на телефоне. Пока сопряжения нет, оно открывает сканер QR-кодов.
3. Отсканируйте код. Приложение покажет найденный узел и попросит подтвердить. В iOS также включите **I agree**, чтобы принять правила публикации контента.
4. Нажмите **Connect**. Телефон соединится с вашим узлом и выполнит сопряжение.

Нет камеры под рукой? Нажмите **Copy connection data** под QR-кодом, отправьте данные на телефон по каналу, которому доверяете, выберите в приложении **Enter pairing data manually** и вставьте их. Любой, у кого есть эти данные, может подключить устройство к вашему узлу.

Телефону и компьютеру не обязательно быть в одной сети Wi-Fi. Приложение сначала пробует локальный адрес узла, затем его публичный адрес, а затем подключается через один из bootstrap-узлов вашего узла. Трафик между телефоном и вашим узлом при этом остается под сквозным шифрованием. Значок монитора на верхней панели приложения горит зеленым, пока узел доступен, и красным, когда недоступен.

Имейте в виду:

- **Узел должен быть запущен, и в нем должен быть выполнен вход**, иначе телефон работать не будет. Если компьютер уснул или приложение закрыто, индикатор на телефоне красный, а телефон продолжает попытки подключиться.
- **Сканируйте код заново после каждого входа.** При каждом входе ваш узел запускается и отменяет сопряжение со всеми телефонами. После перезапуска приложения QR-код новый: отсканируйте его. После выхода и повторного входа без закрытия приложения код остается прежним, но больше не подходит: закройте и откройте приложение, войдите и отсканируйте новый код.
- **Устройствами управляют в Settings → Devices.** Можно подключить до 10 телефонов; кнопка **Remove** сразу отзывает доступ. QR-код никогда не содержит ваш логин, пароль или приватные ключи.

Что содержит QR-код, как телефон подключается и что умеет каждое приложение, описано на странице [Мобильные приложения](mobile.md).

## Что можно делать {#what-you-can-do}

Это сеть в стиле Twitter, в которой нет посредника. Все перечисленное ниже обслуживает ваш собственный узел.

| Раздел | Возможности |
|---|---|
| Публикации | Посты до 2048 байт, ответы, ретвиты, цитаты, редактирование, удаление, закрепленные посты, опросы (до 4 вариантов), изображения и видео, эмодзи |
| Чтение | Главная лента, треды, счетчики просмотров, реакции эмодзи, списки отреагировавших и сделавших ретвит |
| Люди | Профили, подписка и отписка, поиск пользователей (по имени, ID пользователя или адресу в Fediverse), **Who to follow** со статусом «в сети» |
| Сообщения | Личные чаты с текстом, изображениями и видео, доставка напрямую от узла к узлу; пока узел собеседника офлайн, сообщения ждут в очереди до 30 дней |
| Уведомления | Уведомления в приложении; по желанию — e-mail через ваш собственный SMTP-аккаунт (**Settings → Email notifications**) |
| Ваши настройки | Закладки, блокировки, игнорирование (mute), фильтры по ключевым словам. Изображения и видео от людей вне вашего [круга доверия](../trust-circle.md) загружаются только по нажатию; настройка **Show media from unfamiliar authors** в **Settings → Preferences** загружает их сразу |
| Перенос истории | **Import tweets from X** (главный экран или **Settings**): оригинальные посты из вашего архива X, до четырех фотографий в каждом; ответы, ретвиты, GIF и видео пропускаются |
| Другие сети | Аккаунты Mastodon, Threads и Nostr через шлюз моста; см. [Мосты](../bridge.md) |
| Узел | **Settings → Node rating**, **Devices**, **Network**, **Rate limiting**, **Bridge gateway** |
| Экспериментальное | Спонсорские посты, которые читатель открывает, заплатив в USDT в сети TRON, и кошелек TRON (кошелек только в testnet) |

## Жалобы на контент {#report-content}

В посте или профиле выберите **Report**, отметьте одну или несколько причин (спам или мошенничество, травля, язык вражды, насилие или угрозы, сексуальный контент, безопасность детей, самоповреждение или суицид, нарушение приватности, опасный контент или оружие), при желании добавьте комментарий и отправьте жалобу. Пишите комментарий коротко: узел отклоняет жалобу длиннее 256 символов вместе с выбранными причинами.

- Жалобы уходят узлам-модераторам, а не пользователю, на которого вы пожаловались.
- Жалоба содержит ваш ID пользователя, чтобы итог дошел до вас в виде уведомления.
- Пожаловаться можно только на пост или профиль. На личные сообщения пожаловаться нельзя.

Блокировки, игнорирование и фильтры по ключевым словам действуют на вашу собственную ленту сразу и ничьего согласия не требуют. Как выносятся вердикты, описано на странице [Модерация](../moderation.md).

## Где хранятся ваши данные {#where-your-data-lives}

| Система | Папка |
|---|---|
| Linux, macOS | `~/.warpdata/<network>/storage/` |
| Linux (Snap) | `~/snap/warpnet/current/.warpdata/<network>/storage/` |
| Windows | `%LOCALAPPDATA%\warpdata\<network>\storage\` |

`<network>` — это `warpnet` или `testnet`. База данных внутри зашифрована вашим ключом базы данных. Не удаляйте и не перемещайте файлы, пока приложение работает. Чтобы сохранить копию или перейти на другой компьютер, следуйте инструкции [Резервное копирование и восстановление](backup-and-restore.md).

При запуске ваш узел подключается к bootstrap-узлам из своего списка: по умолчанию это relay-узлы проекта. Они помогают вашему узлу находить другие узлы, а если ваш узел за NAT, другие узлы и ваш телефон достучатся до него через них; пересылаемый трафик остается под сквозным шифрованием. Свой список можно задать в **Settings → Network** (применяется после перезапуска узла). См. [Сеть и транспорт](../network.md).
