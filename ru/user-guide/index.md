# Начало работы {#getting-started}

Эта страница проведет вас от загрузки до первого поста. Здесь описано, как установить десктопное приложение, выбрать сеть и создать аккаунт, за что отвечает пароль, как подключить мобильное приложение и где хранятся ваши данные. Страница написана для тех, кто хочет пользоваться Warpnet. Если вы держите постоянно работающий сервер, переходите к странице [Запуск узла](running-a-node.md).

У Warpnet нет серверов и нет компании, которая хранит аккаунты. Приложение, которое вы устанавливаете, *и есть* ваш узел: оно хранит ваш профиль, посты, подписки и чаты на вашем компьютере и напрямую общается с другими узлами. Нигде ничего не регистрируется.

## Установка {#install}

### Компьютер {#desktop}

| Платформа | Где взять | Что запускать |
|---|---|---|
| Linux (Snap) | `sudo snap install warpnet --beta` | `warpnet` |
| Linux x86-64 | `warpnet_linux_amd64.tar.gz` | `warpnet` |
| Linux ARM64 | `warpnet_linux_arm64.tar.gz` | `warpnet` |
| Windows x64 | `warpnet_windows_amd64.zip` | `warpnet.exe` |
| macOS (Intel и Apple silicon) | `warpnet_darwin.tar.gz` | `warpnet.app` |

Архивы прикреплены к каждому [релизу на GitHub](https://github.com/Warp-net/warpnet/releases/latest). Архивы для Linux и Windows также выкладываются на [Codeberg](https://codeberg.org/Warpnet/warpnet/releases). Распакуйте архив и запустите файл из него.

- **Snap.** Сборки публикуются в канале `beta` в Snap Store, поэтому нужен флаг `--beta`. Snap обновляется сам через `snapd`, встроенное обновление приложения там отключено.
- **Архив для Linux.** Приложение — это окно GTK со встроенным WebKit. Для него нужны GTK 3 и WebKitGTK 4.1 (в Debian и Ubuntu пакет называется `libwebkit2gtk-4.1-0`).
- **Сборки из архивов для Windows и Linux** раз в час проверяют GitHub и Codeberg на наличие нового релиза и спрашивают вас перед установкой. Установка перезапускает узел, поэтому после нее нужно войти снова. Чтобы отключить проверку, запускайте приложение с `--node.self-update=false`.

> **Внимание:** Сборка для macOS не подписана и не нотаризована, поэтому Gatekeeper блокирует первый запуск. Попробуйте один раз открыть `warpnet.app`, затем откройте **System Settings → Privacy & Security** (в русской macOS — «Системные настройки → Конфиденциальность и безопасность»), прокрутите вниз, нажмите **Open Anyway** и подтвердите. Сборки для macOS не обновляются автоматически: каждый новый релиз скачивайте сами.
{: .warning }

### Проверка загрузки {#verify-the-download}

У каждого архива есть файл `<name>_checksums.txt` с его хешем SHA-256 и файл `<name>_checksums.txt.sig` с подписью Ed25519 для этого списка. Проверка хеша:

```bash
sha256sum -c warpnet_linux_amd64_checksums.txt        # Linux
shasum -a 256 -c warpnet_darwin_checksums.txt          # macOS
```

В Windows выполните в PowerShell `Get-FileHash warpnet_windows_amd64.zip` и сравните хеш с указанным в `warpnet_windows_amd64_checksums.txt`.

Для проверки подписи нужен OpenSSL 3 или новее. Сохраните ключ релизов проекта в файл `release.pub`:

```text
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEA+PJtnzN+C//o1UVdUWlQkhMPrT0QTZfB+s87rLQgvUk=
-----END PUBLIC KEY-----
```

```bash
base64 -d warpnet_linux_amd64_checksums.txt.sig > listing.sig
openssl pkeyutl -verify -pubin -inkey release.pub -rawin \
  -in warpnet_linux_amd64_checksums.txt -sigfile listing.sig
```

Это тот же ключ, которым встроенный механизм обновления проверяет релиз перед установкой ([`core/selfupdate/selfupdate.go`](https://github.com/Warp-net/warpnet/blob/main/core/selfupdate/selfupdate.go)).

### Телефон {#phone}

Мобильные приложения — компаньоны: они не создают аккаунты, и им нужен запущенный десктопный или удаленный узел, к которому их можно подключить.

| Платформа | Где взять |
|---|---|
| Android 7.0 или новее (ARM64) | [F-Droid](https://f-droid.org/packages/site.warpnet.warpdroid/) или `warpdroid.apk` из релиза на GitHub |
| iOS 17 или новее | [App Store](https://apps.apple.com/app/warpnet/id6835178022) |

Приложение можно установить уже сейчас, но подключайте его после того, как создадите аккаунт: см. [Подключение телефона](#connect-your-phone).

## Выбор сети {#choose-a-network}

У Warpnet две публичные сети, которые никогда не пересекаются:

| Сеть | Имя | Для чего |
|---|---|---|
| Основная | `warpnet` (псевдоним `mainnet`) | Рабочая сеть. Используется по умолчанию. |
| Тестовая | `testnet` | Для экспериментов. Данные в ней могут быть стерты. |

При первом запуске на приветственном экране десктопного приложения под кнопкой **Sign up** есть переключатель **Network**. Если выбрать сеть, приложение перезапустится в ней. Из командной строки:

```bash
warpnet --node.network testnet   # тестовая сеть
warpnet --node.network mainnet   # основная сеть
```

Что нужно знать:

- У каждой сети своя папка с базой данных, поэтому аккаунт в testnet и аккаунт в mainnet — разные, даже с одинаковыми логином и паролем.
- Узлы общаются только с узлами, у которых то же имя сети и та же мажорная версия. Сетевой ключ выводится из обоих значений ([`security/psk.go`](https://github.com/Warp-net/warpnet/blob/main/security/psk.go)): он разделяет сети, но секретом не является.
- Переключатель показывается только на экране первого запуска. Если вы пользуетесь testnet, запускайте приложение с `--node.network testnet` (или `NODE_NETWORK=testnet`), чтобы оно точно открылось в этой сети. Если приложение открылось на экране регистрации основной сети, хотя аккаунт в testnet у вас уже есть, снова выберите **Testnet** в переключателе.
- Кошелек показывается только в testnet.

## Регистрация {#sign-up}

Нажмите **Sign up** на приветственном экране. Мастер регистрации состоит из четырех шагов и показывает индикатор прогресса.

**Шаг 1 из 4: Login.** Введите логин, с которым будете входить. Логин никогда не публикуется: это половина секрета, который открывает ваши данные. Другие видят новый профиль как `Anonymous`, пока вы не укажете в профиле отображаемое имя.

**Шаг 2 из 4: Important information.** Чтобы продолжить, отметьте все четыре утверждения:

| Утверждение | Кратко |
|---|---|
| User Responsibility | Вы отвечаете за то, что загружаете. Оскорбительный контент и агрессивные пользователи недопустимы: на них можно пожаловаться, их можно скрыть и заблокировать. |
| Content Distribution | Все, что вы публикуете, распространяется на другие узлы, которые хранят и показывают это. Сообщения доставляются на узлы получателей. Копии, которые другие узлы уже получили, могут остаться после удаления оригинала. |
| Local Storage Disclaimer | Ваши данные хранятся только на вашем устройстве. Потеряете устройство — потеряете аккаунт. |
| Future Advertising | В Warpnet может появиться спонсорский контент или реклама. |

**Шаг 3 из 4: Password.** Введите пароль дважды. Пункты контрольного списка становятся зелеными по мере выполнения правил, а кнопка **Next** остается неактивной, пока не выполнены все правила и оба поля не совпадают. Пароль должен содержать:

- от 8 до 32 символов
- хотя бы одну заглавную букву (A–Z)
- хотя бы одну строчную букву (a–z)
- хотя бы одну цифру (0–9)
- хотя бы один специальный символ: любой, кроме A–Z, a–z и 0–9 (`_` тоже подходит)

Пробелы в начале и в конце пароля удаляются перед использованием. Узел считает длину в байтах, поэтому буквы не из латинского алфавита (в том числе кириллица) считаются за два символа и больше. **Reveal password** показывает то, что вы ввели. Узел проверяет те же правила ([`cmd/node/member/auth/auth.go`](https://github.com/Warp-net/warpnet/blob/main/cmd/node/member/auth/auth.go)).

**Шаг 4 из 4: Terms.** Прочитайте [Условия использования](../legal/T&C.md) и [Политику конфиденциальности](../legal/PRIVACY-POLICY.md), затем нажмите **Sign up**. Узел создаст зашифрованную базу данных, запустится и подключится к сети.

> **Примечание:** В релизах с 0.8.110 по 0.8.116 на этом шаге также спрашивается, показывать ли ваши посты в Nostr. Узел этот ответ нигде не использует, а новые сборки больше не спрашивают.
{: .note }

После регистрации короткий тур покажет основные части приложения. Повторить его можно из меню аккаунта.

## Пароль — это ваша личность {#your-password-is-your-identity}

Прочитайте этот раздел дважды. Логин и пароль используются для двух вещей ([`security/kdf.go`](https://github.com/Warp-net/warpnet/blob/main/security/kdf.go)):

| Из чего выводится | Что это | Для чего нужен |
|---|---|---|
| логин + пароль | ключ базы данных (Argon2id) | Шифрует локальную базу данных: профиль, посты, подписки, чаты, настройки. |
| логин + пароль + сеть | ключ идентичности (Argon2id, Ed25519) | Ваш ID узла и подпись под всем, что отправляет ваш узел. |

Ни один из ключей не хранится на диске. Они существуют только после входа. Отсюда следует:

- **Сбросить пароль нельзя.** Ни у кого нет копии вашего пароля или ключей.
- **Сменить пароль нельзя.** Из другого пароля получаются другой ключ базы данных и другая идентичность, поэтому он не откроет ваши существующие данные.
- **Те же логин и пароль на другом компьютере дают тот же ID узла, но не ваш аккаунт.** Ваш ID пользователя, профиль, посты, подписки и чаты хранятся в базе данных. Без копии папки с базой вы начнете с пустого профиля. См. [Резервное копирование и восстановление](backup-and-restore.md).
- **Выход из аккаунта останавливает узел.** Подключенные телефоны не смогут до него достучаться, пока вы снова не войдете. Чтобы спрятать окно за PIN-кодом и оставить узел работать, используйте **Settings → Screen lock** (в десктопном приложении).

## Подключение телефона {#connect-your-phone}

У приложений для Android и iOS нет собственных аккаунтов. Телефон подключается к только что созданному узлу и работает через него, поэтому аккаунт, ключи и данные остаются на компьютере.

1. Установите приложение: [F-Droid](https://f-droid.org/packages/site.warpnet.warpdroid/) (Android 7.0+) или [App Store](https://apps.apple.com/app/warpnet/id6835178022) (iOS 17+).
2. На компьютере войдите в Warpnet, откройте меню аккаунта и выберите **Sign in by QR-code** (вход по QR-коду). Появится QR-код.
3. Откройте приложение на телефоне. При первом запуске оно сразу открывает сканер QR-кодов.
4. Отсканируйте код. Приложение покажет ваш узел, его владельца и адрес. В iOS также включите **I agree**, чтобы принять правила публикации контента.
5. Нажмите **Connect**. Телефон соединится с вашим узлом и выполнит сопряжение.

Нет камеры под рукой? Нажмите **Copy connection data** под QR-кодом, отправьте данные на телефон по каналу, которому доверяете, затем выберите в приложении **Enter pairing data manually** и вставьте их. Любой, у кого есть эти данные, может подключить устройство к вашему узлу.

Телефону и компьютеру не обязательно быть в одной сети Wi-Fi. Приложение сначала пробует локальный адрес узла, затем его публичный адрес, а если не получается — подключается через relay-узел. Трафик между телефоном и вашим узлом при этом остается под сквозным шифрованием. Значок монитора на верхней панели приложения горит зеленым, пока узел доступен, и красным, когда недоступен.

Имейте в виду:

- **Узел должен быть запущен, и в нем должен быть выполнен вход**, иначе телефон работать не будет. Если компьютер уснул или приложение закрыто, индикатор на телефоне красный, а телефон продолжает попытки подключиться.
- **После перезапуска узла отсканируйте код заново.** Токен сопряжения меняется при каждом запуске десктопного приложения, поэтому после перезапуска приложения или компьютера телефон попросит отсканировать новый код.
- **Устройствами управляют в Settings → Devices.** Можно подключить до 10 телефонов; кнопка **Remove** сразу отзывает доступ. QR-код никогда не содержит ваш пароль или ключи, поэтому потерянный телефон можно удалить без риска для аккаунта.

Что содержит QR-код, как приложение работает в фоне на Android и что умеет каждое приложение, описано на странице [Мобильные приложения](mobile.md).

## Что можно делать {#what-you-can-do}

Это сеть в стиле Twitter, в которой нет посредника. Все перечисленное ниже обслуживает ваш собственный узел.

| Раздел | Возможности |
|---|---|
| Публикации | Посты до 2048 байт, ответы, ретвиты, цитаты, редактирование, удаление, закрепленные посты, опросы (до 4 вариантов), изображения и видео, эмодзи |
| Чтение | Главная лента, треды, счетчики просмотров, реакции эмодзи, списки отреагировавших и сделавших ретвит |
| Люди | Профили, подписка и отписка, запросы на подписку, поиск пользователей по имени, ID пользователя или адресу в Fediverse, **Who to follow** со статусом «в сети» |
| Сообщения | Личные чаты с текстом, изображениями и видео, доставка напрямую от узла к узлу; если узел собеседника офлайн, сообщения ждут в очереди до 30 дней |
| Уведомления | Уведомления в приложении; по желанию — доставка по e-mail через ваш собственный SMTP-аккаунт (**Settings → Email notifications**) |
| Ваши настройки | Закладки, блокировки, игнорирование (mute), фильтры по ключевым словам; по желанию — скрытие изображений и видео от людей вне вашего [круга доверия](../trust-circle.md) до нажатия (**Settings → Preferences**) |
| Перенос истории | **Import tweets from X**: оригинальные посты и их фотографии из вашего архива X (ответы, ретвиты, лайки, личные сообщения, GIF и видео пропускаются) |
| Другие сети | Аккаунты Mastodon, Threads и Nostr через шлюз моста; см. [Мосты](../bridge.md) |
| Узел | **Settings → Node rating**, **Devices**, **Network**, **Rate limiting**, **Bridge gateway** |
| Экспериментальное | Спонсорские посты (читатель один раз платит в USDT в сети TRON, чтобы открыть пост) и кошелек TRON для оплаты (кошелек только в testnet) |

Публичные посты передаются от пира к пиру. Ваша лента, чаты, закладки и черновики остаются на вашем узле и на узлах людей, с которыми вы общаетесь.

Ручное одобрение подписчиков (закрытый аккаунт) пока можно включить только в приложении для Android; десктопное приложение показывает запросы на подписку и позволяет на них отвечать.

## Жалобы на контент {#report-content}

В посте или профиле выберите **Report**, отметьте одну или несколько причин (спам или мошенничество, травля, язык вражды, насилие, сексуальный контент, безопасность детей, самоповреждение, нарушение приватности, опасный контент), при желании добавьте пояснение до 500 символов и отправьте жалобу.

- Жалобы уходят узлам-модераторам в сети. Пользователь, на которого вы пожаловались, об этом не узнает.
- Жалоба содержит ваш ID пользователя, чтобы результат дошел до вас. Модераторы его видят, а пользователь, на которого вы пожаловались, — нет.
- На личные сообщения пожаловаться нельзя, и они никогда не модерируются.
- Вы получите одно уведомление с итогом.

В вашей собственной ленте блокировки, игнорирование и фильтры по ключевым словам действуют сразу и ничьего согласия не требуют. Как выносятся вердикты, описано на странице [Модерация](../moderation.md).

## Где хранятся ваши данные {#where-your-data-lives}

| Система | Папка |
|---|---|
| Linux, macOS | `~/.warpdata/<network>/storage/` |
| Linux (Snap) | `~/snap/warpnet/current/.warpdata/<network>/storage/` |
| Windows | `%LOCALAPPDATA%\warpdata\<network>\storage\` |

`<network>` — это `warpnet` или `testnet`. База данных внутри зашифрована вашим ключом базы данных. Не удаляйте и не перемещайте файлы, пока приложение работает. Чтобы сохранить копию или перейти на другой компьютер, следуйте инструкции [Резервное копирование и восстановление](backup-and-restore.md).

Ваш узел подключается к сети через relay-узлы (bootstrap). Они помогают узлам находить друг друга и пересылают зашифрованный трафик узлов за NAT. Прочитать этот трафик они не могут и ваших данных не хранят. См. [Сеть и транспорт](../network.md).
